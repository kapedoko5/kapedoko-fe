# Admin vibe tag catalog

## Scope and visitor mode

Operate. Staff ledger for naming cafe vibe stamps. Job is to create, enable, disable, and delete the vocabulary owners pick from.

## Audience, job, action, constraints

KapeDoko admins at a desk. Name a stamp (label + Lucide + hex color for fill and border), keep a dense list, disable to hide it from cards without dropping assignments, delete only when no cafe uses it. Inherit bag-label world. Not a filter catalog.

## Direction and memorable moment

Same ink ledger as Badges, with a live stamp preview. Memorable moment is inking a name, icon, and color into a tilted stamp on the form.

## Unresolved decisions

None. Owners and admins assign stamps from cafe edit, not from this catalog.

## Direction contract

THESIS: A named-stamp ledger, not a badge award desk and not a tag cloud.

OWN-WORLD: Shelf #F2F2F2, stock #FAF8F5, ink #1c1917, catalog color on stamp fill and border, teal chrome. Kumbh Sans. 16px panels, 8px stamp corners, no lift shadows.

STORY: Admin names Quiet, picks the mute icon and a color, saves, and owners can stamp it.

FIRST VIEWPORT: Stock nav, Vibe tags selected, orange Add vibe tag. Ledger of colored stamp, cafe count, enabled/disabled, Edit / Disable. Empty copy teaches that owners cannot pick until a name exists. Form: swatch + hex next to the icon grid, live preview of fill and border.

FORM: Local extension of the admin desk; code-led.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
